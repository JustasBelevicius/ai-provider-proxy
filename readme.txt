Proxy provider scaffold for the WordPress AI Client.

== Description ==

AI Provider Proxy provides the plugin structure for a proxy-based AI provider integration.

== Installation ==

1. Copy the `ai-provider-proxy` directory to `wp-content/plugins/`.
2. Activate AI Provider Proxy in WordPress.
